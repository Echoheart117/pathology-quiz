# 病理学刷题本

13 章、2,648 题，支持章节和语言筛选、顺序与随机练习、错题、收藏、笔记及记录备份。

789 道英文题提供中文学习解析，作答或查看答案后显示，并附知识点参考资料。解析由 AI 辅助整理，尚未经医学教师逐题审定，不属于官方答案。

原书答案与订正说明分别保存。17 处明确订正采用新答案；58 道争议、答案不明或缺图题暂不计分。解析中发现的疑点不会直接改写原书答案。

公开版本只包含网页、题库数据和做题必需的配图，不提供原始 PDF 或扫描答案图片。学习记录保存在当前浏览器，换设备时请导出、导入备份。

GitHub Pages 从 main 分支根目录发布。可直接打开 index.html 本地使用。
