# 病理学刷题本

13 章、2,648 题，支持章节和语言筛选、顺序与随机练习、错题、收藏、已熟练与视频没讲标记、Markdown 图片笔记、题目文本导出及记录备份。

桌面页面采用题目与做题笔记双栏布局，两栏独立滚动，翻页按钮固定在题目栏底部。

“已熟练”由用户手动标记与取消，答对不会自动标记；状态保存在浏览器并随学习记录备份迁移。

“争议题”支持个人手动标记与取消，纳入备份，不改变参考答案和计分规则。

未熟练题再次进入时重新作答，上次计分保留到再次提交；已熟练题保持原作答。

支持“复制题目图片”，可将题干、选项、配图和当前已展开的翻译复制到剪贴板，不包含答案或做题笔记。

题目提供“显示中文翻译”开关。中文题中的英文词或术语在旁边显示中文意思，英文长句提供整句译文；题干和选项均可翻译。翻译在作答前也能查看，切题后默认隐藏。

原书答案与订正说明分别保存。17 处明确订正采用新答案；58 道争议、答案不明或缺图题暂不计分，原书答案保留。

公开版本包含题库配图、原题 PDF、修正版答案 PDF 和扫描答案图片，支持查看原页以核对资料。学习记录与笔记图片保存在当前浏览器，换设备时请导出、导入备份。本网站与解剖题库独立。

GitHub Pages 从 main 分支根目录发布。可直接打开 index.html 本地使用。
